# Идея: Интеллектуальный ассистент для банковского обслуживания

## Описание проекта

Telegram-бот для автоматизации консультаций клиентов банка по продуктам и услугам. Бот работает на базе искусственного интеллекта и самостоятельно принимает решения о том, когда нужно искать информацию в документах банка, а когда может ответить напрямую.

## Бизнес-задача

**Проблема:**
- Клиенты банка задают множество повторяющихся вопросов о кредитах, вкладах и условиях обслуживания
- Операторы тратят время на поиск информации в объемных документах
- Необходимость обеспечить круглосуточную поддержку клиентов

**Решение:**
Интеллектуальный ассистент, который:
- Мгновенно отвечает на вопросы клиентов 24/7
- Автоматически находит нужную информацию в документах банка
- Понимает контекст диалога и уточняющие вопросы
- Всегда дает актуальные ответы на основе загруженных документов

## Ключевые возможности

### Для клиентов

**Естественный диалог:**
- Клиент задает вопросы обычным языком в Telegram
- Бот понимает контекст беседы и помнит предыдущие сообщения
- Можно задавать уточняющие вопросы без необходимости повторять контекст

**Примеры диалога:**
```
👤 Какие условия потребительского кредита?
🤖 Кредит от 30 000 до 5 000 000 рублей на срок от 3 месяцев 
   до 5 лет. Ставка от 12.9% до 19.9% годовых...

👤 А можно досрочно погасить?
🤖 Да, досрочное погашение возможно без комиссий...
```

**Прозрачность источников:**
- Опционально показывает документы и страницы, откуда взята информация
- Клиент может проверить достоверность ответа

### Для бизнеса

**Автономность (ReAct Agent):**
- Бот использует паттерн ReAct (Reason + Act) для принятия решений
- **Think (Reason)**: анализирует вопрос и контекст диалога
- **Act**: вызывает инструмент `rag_search` только если нужна информация из документов
- **Respond**: формирует ответ на основе найденных данных или собственных знаний
- Не требует ручной настройки сценариев для каждого вопроса
- Адаптируется к любым вопросам в рамках загруженной документации
- Примеры автономных решений:
  - "Привет" → отвечает напрямую, без поиска
  - "Какие условия кредита?" → использует rag_search для поиска точной информации
  - "Спасибо" → отвечает напрямую

**Качество обслуживания:**
- Консистентные ответы на основе официальных документов
- Нет риска устаревшей информации - при обновлении документов бот использует актуальные данные
- Несколько режимов поиска для максимальной точности ответов

**Масштабируемость:**
- Обслуживает неограниченное количество клиентов одновременно
- Легко добавить новые документы - просто загрузить PDF
- Работает круглосуточно без выходных

### Для управления

**Мониторинг и контроль:**
- Отслеживание всех диалогов и запросов клиентов
- Анализ производительности и качества ответов
- Выявление частых вопросов для улучшения документации

**Оценка качества:**
- Автоматическая проверка точности ответов по тестовым вопросам
- Метрики качества: достоверность, релевантность, правильность
- Сравнение разных режимов работы для выбора оптимального

**Управление знаниями:**
- Простое обновление базы знаний через загрузку PDF
- Автоматическая индексация новых документов
- Команды для проверки статуса и переиндексации

## Эволюция функционала

### Этап 1: Базовый ассистент ✅
- Ответы на основе документов банка
- Контекстные диалоги с пониманием уточнений
- Работа через Telegram
- Автоматическая обработка PDF документов

### Этап 2: Улучшение поиска ✅
- Несколько режимов поиска информации (базовый, расширенный, точный)
- Облачный и локальный варианты работы
- Гибкая настройка под разные требования к скорости и качеству

### Этап 3: Мониторинг и контроль качества ✅
- Отображение источников информации для прозрачности
- Интеграция с системой мониторинга диалогов
- Автоматическая оценка качества ответов
- Создание тестовых наборов вопросов

### Этап 4: Автономный интеллектуальный агент (ReAct) ✅
- **ReAct паттерн** - Reason + Act: агент рассуждает, затем действует
- Самостоятельное принятие решений о необходимости поиска информации
- Умный выбор стратегии: когда искать в документах, когда отвечать напрямую
- Инструмент `rag_search` вызывается только при необходимости
- Адаптивное поведение под разные типы вопросов
- История диалога управляется через MemorySaver (сохранение контекста между сообщениями)

### Этап 5: MCP интеграция для динамических данных ✅
- **Model Context Protocol (MCP)** - стандартизированный протокол для расширения возможностей агента
- Инструмент `search_products` - поиск актуальных продуктов банка с текущими ставками
- Инструмент `currency_converter` - конвертация валют по актуальным курсам ЦБ РФ
- Разделение источников данных: статические PDF vs динамические API
- Модульная архитектура: MCP серверы как отдельные микросервисы
- Легко расширяется новыми инструментами без изменения кода агента

**Примеры использования новых инструментов:**
```
👤 Какие сейчас ставки по вкладам?
🤖 [search_products] → Актуальные вклады:
   • Пополняй - 15.5% годовых, от 1000₽
   • Сохраняй - 16.0% годовых, от 50000₽
   ...

👤 Какой сейчас курс доллара?
🤖 [currency_converter] → Курс USD к RUB: 97.88₽
   (данные ЦБ РФ на сегодня)

👤 А 100 долларов это сколько рублей?
🤖 [currency_converter] → 100 USD = 9,788₽
```

**Преимущества MCP подхода:**
- Динамические данные всегда актуальны (курсы валют, ставки)
- Изоляция логики в отдельных серверах
- Стандартизированный протокол (совместимость с экосистемой MCP)
- Возможность использовать готовые MCP серверы
- HTTP транспорт - можно разнести на разные хосты

### Этап 6: Расчётные финансовые инструменты (MCP) ✅

*Домашнее задание модуля (ДЗ-08): часть 2 — этот этап; часть 1 — проверка MCP после этапа 5.*

- Инструмент `calculate_deposit_profit` — расчёт накопленной суммы и дохода по вкладу с учётом ежемесячной капитализации процентов (или без неё)
- Не зависит от внешних API: расчёт на стороне MCP сервера по введённым клиентом сумме, ставке и сроку
- Дополняет `search_products` (актуальные продукты) и официальные документы: клиент может сравнить сценарии «что будет, если положить X под Y% на Z месяцев»

**Пример диалога:**
```
👤 Сколько заработаю на вкладе 100 000₽ под 15% на 12 месяцев с капитализацией?
🤖 [calculate_deposit_profit] → Итого: 116 075₽, доход: 16 075₽
```

## Преимущества решения

**Снижение нагрузки на операторов:**
- Типовые вопросы обрабатываются автоматически
- Операторы могут сфокусироваться на сложных кейсах

**Улучшение клиентского опыта:**
- Мгновенные ответы в любое время
- Последовательные и точные консультации
- Удобный канал коммуникации (Telegram)

**Гибкость и контроль:**
- Легко обновлять информацию
- Настройка режимов работы под разные задачи
- Полная прозрачность источников ответов

**Масштабируемость:**
- Растет вместе с бизнесом
- Можно добавить новые продукты и услуги
- Поддержка множества клиентов без дополнительных затрат

**Минимальные требования:**
- Telegram Bot токен
- Документы банка в PDF формате
- Доступ к облачным AI сервисам

**Быстрый старт:**
1. Загрузить документы банка
2. Настроить подключение к AI
3. Запустить бота
4. Начать обслуживание клиентов

**Обслуживание:**
- Добавление новых документов - простая загрузка файлов
