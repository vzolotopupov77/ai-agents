## Цель

Зафиксировать поведение агента с **двумя** инструментами (`rag_search`, `currency_converter`), сопоставить вопросы пользователя с вызовами в LangSmith и подготовить **скриншот** для сдачи домашней работы.

## Что должно быть готово после итерации 1

- Бот запускается, в `.env` при необходимости заданы переменные для LangSmith (`LANGCHAIN_*` или совместимые `LANGSMITH_*` через `config`).
- Инструмент `currency_converter` подключён к агенту.

## Сценарии для прогона (совпадают с проверками U1–U5)

Прогоните в Telegram **одним пользователем** (или по очереди), затем сверьтесь с трейсами в [LangSmith](https://smith.langchain.com/) в проекте из `LANGCHAIN_PROJECT` / `LANGSMITH_PROJECT`.

| ID | Реплика пользователя | Ожидание по инструментам |
|----|----------------------|---------------------------|
| U1 | «Привет» (или аналог) | Без вызова `rag_search` и без `currency_converter` |
| U2 | Продуктовый вопрос, например «Какие условия потребительского кредита?» | Вызов `rag_search`, не `currency_converter` |
| U3 | Конвертация, например «Сколько будет 500 долларов в рублях?» | Вызов `currency_converter` (аргументы USD → RUB и сумма) |
| U4 | Кросс-курс, например «100 евро в тенге» | Вызов `currency_converter` (EUR → KZT или через логику агента) |
| U5 | — | В LangSmith в выбранном **thread/run** видна цепочка шагов агента до финального ответа |

Если ЦБ недоступен из сети, в ответе инструмента будет указан запасной источник курсов — это нормально для наблюдения.

## Что смотреть в LangSmith

1. Проект → **Threads** (или список runs) → открыть трассировку, соответствующую сообщению в Telegram.
2. Убедиться, что есть шаги модели и при необходимости блок **Tools** с именами `rag_search` / `currency_converter`.
3. Зафиксировать **на какой реплике** какой инструмент вызывался (для таблицы ниже).

- скрин переписки в Telegram, где виден вопрос про валюту и ответ бота с суммой/курсом; **или**
- скрин LangSmith с видимым вызовом `currency_converter` (или всего trace для этого сообщения).

Сохраните файл локально и приложите к сообщению сдачи по правилам курса.
