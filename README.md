## Как запускать

Общий минимум: **Python 3.12**, **uv**, в каталоге модуля — `uv sync`, копирование `.env.example` → `.env`, далее команды из README модуля (`make setup` / `make run`, `uv run python -m aidd`, Docker — где описано).
