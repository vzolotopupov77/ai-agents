# ADR 0004: Независимость слоя LLM от Telegram

**Статус:** принято  
**Дата:** 2026-05-04

## Контекст

Обработчики aiogram должны оставаться тонкими; логика формирования ответа LLM не должна быть связана с типами Telegram (Message, Chat и т.д.), чтобы не смешивать транспорт и доменную задачу «диалог с моделью».

## Решение

Модуль (класс) работы с LLM принимает и возвращает данные в терминах **сообщений чата** (роль, текст), без импортов aiogram. Сборка списка сообщений и передача текста ответа в чат остаются в слое, который знает и Telegram, и хранилище.

## Последствия

- Проще тестировать и менять способ доставки (не только Telegram) при сохранении того же контракта сообщений.
- Чуть больше шаблонного кода на границе (маппинг Telegram → сообщения для API).
