# ADR 0001: Хранение истории диалогов только в памяти

**Статус:** принято  
**Дата:** 2026-05-04

## Контекст

Нужно сохранять контекст беседы с пользователем для последовательных запросов к LLM. Для MVP важна скорость проверки идеи и минимальная сложность.

## Решение

История диалога хранится в структурах данных Python в памяти процесса (например `dict[int, list[...]]` с ключом `chat_id`). Никаких СУБД и файлового персистентного хранилища на этапе MVP.

## Последствия

- Перезапуск процесса теряет всю историю — приемлемо для проверки гипотезы.
- Не нужны миграции, подключение БД и операции с диском для состояния диалога.
- Масштабирование на несколько инстансов без общего хранилища невозможно; вне скоупа MVP.
