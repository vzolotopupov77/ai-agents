# ADR 0003: OpenRouter через официальный клиент OpenAI

**Статус:** принято  
**Дата:** 2026-05-04

## Контекст

Нужен доступ к языковым моделям; OpenRouter даёт единую точку и выбор модели. В экосистеме Python распространён клиент `openai`, совместимый с OpenAI API.

## Решение

Использовать пакет **openai** (официальный SDK): задать `base_url` на endpoint OpenRouter, модель и ключ — из конфигурации. Не подключать отдельный SDK только ради OpenRouter, если достаточно совместимого API.

## Последствия

- Один знакомый интерфейс клиента; меньше кода обёрток.
- Смена провайдера или URL — через конфиг без смены библиотеки (при сохранении совместимости API).
