# ADR 0002: Long polling для Telegram Bot API

**Статус:** принято  
**Дата:** 2026-05-04

## Контекст

Боту нужен способ получать входящие сообщения. Webhook требует публичного HTTPS и настройки на стороне Telegram; для локальной разработки и MVP это лишняя сложность.

## Решение

Использовать **long polling** через aiogram: процесс сам опрашивает API Telegram и забирает обновления. Webhook не используется.

## Последствия

- Не нужен публичный URL и TLS для приёма webhook.
- Один активный процесс с polling достаточен для MVP.
- При будущем переходе на webhook потребуется отдельное решение и ADR.
