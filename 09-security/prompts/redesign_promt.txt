Развиваем проект.
Добавляем в MCP сервер mcp-bank-agent инструменты:
- open_credit_card — инструмент выполняет открытие кредитной карты (эмуляция, мок-реализация логирует результат и возвращает номер карты с доп. информацией, номер карты возвращается без маскирования)

Добавляем агенту:
- новый инструмент через MCP client с указанием в системном промпте инструкций и примеров вызова инструментов
- при вызове инструмента open_credit_card агент должен запросить подтверждение пользователя через human-in-the-loop прерывание (как в референс-тетрадке раздел 5: Версия 1 — Агент с human-in-the-loop) — реализуем только accept и reject, edit не поддерживаем
- в Telegram-боте клиент должен увидеть кнопки Accept и Reject под ответом бота с запросом на согласование операции с указанием деталей операции
- обработка нажатия такой кнопки должна уходить командой агенту для выполнения или отмены операции (после нажатия кнопку удалять из диалога бота, чтобы лишний раз не нажимали)

## Важные указания общего характера:
- Используй референсную тетрадку ../slides/notebooks/agent-guards-demo.ipynb
- Функция вызова агентов должна быть переписана по примеру референса в тетрадке run_turn_agent
- Поддерживай модульную организацию кода
- Обязательные технологии: Python, uv для управления зависимостями и виртуальным окружением, make для сборки и запуска проекта
